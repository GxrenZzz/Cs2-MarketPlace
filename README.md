# CS2 Marketplace Backend

A backend application for a Counter-Strike 2 (CS2) skin marketplace where buyers and sellers can interact to buy and sell in-game skins.

The long-term goal is to provide the backend infrastructure for marketplace operations, including skin management and, eventually, buyer and seller interactions.

## Current Implementation

The current version provides REST API endpoints for managing CS2 skins, including:

- Creating skins
- Retrieving all skins
- Retrieving a skin by ID
- Updating existing skins
- Deleting skins

The application is built using FastAPI and follows a modular architecture with separate API, service, and repository layers.


## Installation

### Prerequisites

Make sure you have the following installed:

- Python 3.14+
- [uv](https://docs.astral.sh/uv/)

### Clone the repository

```bash
git clone https://github.com/GxrenZzz/Cs2-MarketPlace
cd backend
```

### Install dependencies

```bash
uv sync
```

This installs the project dependencies and creates the virtual environment if necessary.
